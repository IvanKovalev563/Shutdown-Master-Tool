# Shutdown Master Tool

**Shutdown Master Tool** - is a lightweight desktop tool that allows you to schedule a computer shutdown or restart with a customizable visual countdown timer. This program based on C#, WinForms and .NET Framework 4.7.2. Now it also supports **rebooting directly into BIOS/UEFI** (requires administrator privileges and UEFI‑based system).

## FAQ

> [!NOTE]
> 
> *What's Shutdown Master Tool?*
> 
> [Shutdown Master Tool](https://github.com/IvanKovalev563/Shutdown-Master-Tool) - is a lightweight desktop tool that allows you to schedule a computer shutdown or restart with a customizable visual countdown timer. This program based on C#, WinForms and .NET Framework 4.7.2.

> [!TIP]
> 
> *How to use the program?*
> 
> 1. Choose *delay* to shutdown or reboot your PC.
> 2. Choose *shutdown or reboot* mode.
> 3. Click *"Shutdown" or "Reboot"* button to start timer.

> [!TIP]
> *Can I change the interface language?*
> 
> Yes. The program supports **Russian** and **English**. You can switch the language at any time from the main menu - no restart required.

> [!TIP]
> 
> *How to reboot into BIOS/UEFI?*
> 
> Select **"Reboot to BIOS"** mode, set the delay, and click the button.  
> **Important notes:**
> - This feature requires **administrator privileges** - run the program as Administrator.
> - It works only on systems with **UEFI** (not legacy BIOS) - the program automatically hides the option if UEFI is not supported.

> [!IMPORTANT]
> 
> *Why is Windows Defender complaining during installation?*
> 
> Just click on `More info` and it will let you install. It complains because the executable is not signed.
